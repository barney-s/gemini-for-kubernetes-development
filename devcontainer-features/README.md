# Devcontainer Features

This directory contains a collection of devcontainer features that can be used to customize your development environment.

## Available Features

- **[antigravity](./antigravity)**: Installs the antigravity package.
- **[gemini-cli](./gemini-cli)**: Installs the Gemini CLI.
- **[sandbox-essentials](./sandbox-essentials)**: Installs tools required for gemini-for-kubernetes-development sandboxes.
