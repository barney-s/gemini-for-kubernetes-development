# Sandbox Essentials (sandbox-essentials)

Installs tools required for gemini-for-kubernetes-development sandboxes.

## Example Usage

```json
{
    "image": "mcr.microsoft.com/devcontainers/base:ubuntu",
    "features": {
        "./features/sandbox-essentials": {}
    }
}
```
